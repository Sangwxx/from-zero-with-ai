# 从零开始的 AI 协作生活

> 我的 AI 工作与科研实践

这个仓库记录我如何把 AI 真正融入日常工作和科研，而不只是收集提示词或展示工具。

每一章尽量回答四个问题：

1. 我当时遇到了什么真实问题？
2. 我先通过手工操作理解了什么？
3. 哪些重复工作后来交给了 AI？
4. 最终形成了什么可以继续复用的工作流？

## 写作原则

- 记录真实过程，包括失败、误解和修正。
- 先解释工具背后的逻辑，再介绍自动化。
- AI 生成内容与文献事实、实验数据分开。
- 不公开密码、令牌、本机用户名和私人资料。
- 教程中的路径使用通用示例，读者需要替换成自己的路径。

## 后续计划

本仓库将持续更新我在学习、工作和科研中使用 AI 的真实经历、思考与实践。
